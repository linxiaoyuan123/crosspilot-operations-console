# 两分钟演示稿

## 00:00-00:20 项目定位

“这是我独立完成的 SupportOps Console，用来模拟实施工程师和技术支持工程师的日常工作。它把工单、实施交付、网络诊断和知识库放在同一个可运行系统里。后端使用 Node.js 内置模块，数据落在 SQLite，可以本地运行，也可以用 Docker Compose 部署。”

## 00:20-00:45 运行概览

“首页直接展示当前待处理工单、已解决工单、实施项目和风险事项。右侧是交付进度和操作轨迹，能快速看到今天需要优先处理的内容。”

## 00:45-01:10 工单闭环

新建一张工单，填写客户、优先级、负责人和问题描述。随后打开工单，将状态更新为“已解决”，补充解决记录。这里演示的是从受理、处理、反馈到关闭的完整流程。

## 01:10-01:30 实施交付

进入实施交付页面，把项目的当前步骤从“业务数据核对”更新为“用户培训”，同时调整进度。项目状态、计划完成日期和负责人都会持久化到数据库。

## 01:30-01:50 诊断工具

在诊断工具执行本应用健康检查，然后执行 DNS 或 TCP 检查。后端会真实调用 Node.js 的 DNS、Socket、HTTP 或系统 Ping 能力，并保存检查历史。

## 01:50-02:00 工程化收尾

“项目包含自动化测试、GitHub Actions、Dockerfile、健康检查和持久化数据卷。代码没有第三方运行依赖，审查者可以直接运行和验证。”
