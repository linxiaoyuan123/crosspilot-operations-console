# CrossPilot 使用指南

这份指南说明如何完成一次完整的 CrossPilot 运营闭环。默认店铺为 `AuroraHome Europe`，平台为 Amazon，市场为欧洲站，币种为 EUR。所有数据均为模拟或脱敏数据。

## 1. 切换店铺并查看总览

使用右上角“当前店铺”切换模拟店铺。Amazon 店铺是完整演示案例，TikTok Shop 和 Shopee 用于说明多平台字段兼容方式。

“运营总览”优先检查：

- 净销售额和净利润率
- 广告占比、ACOS 和 TACOS
- 库存风险 SKU 数
- 退货率、评分和评论数
- 待执行动作和待处理售后
- 低利润或亏损 SKU 异常榜

指标和异常榜可以继续进入对应模块处理。

## 2. 导入 CSV 或 XLSX

进入“数据导入”：

1. 拖拽文件到上传区，或点击选择文件。
2. 等待系统自动识别商品表现、广告搜索词、库存或退货评论报表。
3. 检查源字段和标准字段的映射。
4. 查看可入库、错误行和 PII 跳过数量。
5. 必要时调整映射并点击“应用映射”。
6. 点击“确认入库”。

单次文件不能超过 10 MB 或 20,000 行。买家姓名、邮箱、电话、地址等 PII 字段会显示为“PII 跳过”，其值不进入预览、数据库和报告。

常见商品表现字段包括 SKU、商品标题、售价、采购成本、销量、销售额、广告费、广告销售、退货数量、评分和评论数。

## 3. 检查利润和 Listing

进入“Listing与商品”：

- 左侧选择 SKU。
- 查看标题、五点、图片、属性、关键词覆盖和合规性分数。
- 查看净利润、利润率、ACOS、TACOS、退货率和可售天数。
- 核对采购成本、平台佣金、履约费、退款损失和广告费。
- 查看盈亏平衡价和建议售价。
- 点击“生成资料包”获取文案骨架和图片需求清单。

当售价或成本发生变化时，先修正基础数据，再根据建议售价检查是否能够覆盖目标利润率。

## 4. 优化广告和流量

进入“广告与流量”：

- 按搜索词检查点击、花费、广告销售、订单、ACOS、ROAS、CVR 和 CPC。
- 筛选精确否词、降价、暂停和放量候选。
- 将建议转入动作中心，填写负责人和截止时间。
- 执行后记录实际结果和证据。

默认目标 ACOS 从店铺配置读取。15 次点击无订单会进入否词候选；花费较高且 ACOS 超过目标 1.5 倍会进入降价或暂停候选；有订单且 ACOS 达标会进入加预算候选。

## 5. 处理库存和补货

进入“库存与履约”：

- 查看可售、在途、预留、残次品和日均销量。
- 检查可售天数、覆盖天数、安全库存和建议补货量。
- 区分缺货风险和滞销风险。
- 将补货或清库存任务分配给负责人。

默认规则是：覆盖天数低于采购交期加 14 天安全期时标记为缺货风险，高于 90 天时标记为滞销风险。

## 6. 处理售后与账号健康

进入“售后与账号”：

- 按类型、状态和优先级查看差评、退货、消息、索赔和履约问题。
- 检查超时、今日到期和处理中数量。
- 查看店铺评分、订单缺陷率、迟发率和取消率。
- 将超时问题转为动作，填写责任人和处理证据。

默认账号健康预警线为评分低于 4.0、订单缺陷率高于 1%、迟发率高于 4.0%、取消率高于 2.5%。

## 7. 执行动作并形成闭环

动作中心汇总利润、Listing、广告、库存、售后和账号健康问题。每个动作应包含：

- 分类、标题和问题说明
- 优先级和负责人
- 截止时间
- 推荐来源和证据
- 执行结果与关闭时间

动作可以执行、延期、关闭或重新打开。每次变更都会写入时间线，方便复盘时说明“发现了什么、采取了什么、结果如何”。

## 8. 生成运营复盘

进入“运营复盘”：

- 查看日报、周报或月报汇总。
- 检查关键指标、异常和未关闭事项。
- 选择 HTML、Markdown、CSV 或 XLSX 导出。
- XLSX 报告包含 `Summary`、`SKU`、`Ads`、`Inventory`、`After-sales` 五个工作表。

导出前确认店铺、日期范围、数据模式和结论。演示数据只用于项目展示，不应被描述为真实店铺业绩。

## 9. 维护文章和审核发布

主导航中的“文章”包含全部文章、归档、分类、标签、系列、全文搜索和内容后台。主页与文章页使用独立 URL，并共享 SQLite 中的同一份内容。

撰写和发布流程：

1. 进入“文章 → 内容后台”，点击“新建文章”。
2. 填写标题、分类、标签、摘要和封面；在 CodeMirror 中编辑正文。
3. 使用工具栏插入标题、粗体、列表、引用、链接、表格和代码块。
4. 拖拽或粘贴图片，上传正文图片和封面。
5. 完成后点击“刷新预览”，保存为草稿。
6. 点击“送审”，文章进入“待审核”。
7. 审核人在编辑器中查看待审文章，点击“通过并发布”或“驳回”。
8. 驳回时会填写原因，文章回到草稿并显示原因。
9. 审核通过后，文章可以立即发布，或设置未来时间定时发布。
10. 到达定时时间后，文章状态从“待发布”变为“已发布”，前台才可见。

内容后台支持新建、编辑、删除 Markdown 文章；设置摘要、分类、标签、系列、封面、置顶和定时发布；审核、拒绝或删除匿名留言；管理媒体库和运营动态、案例项目、证据相册、资源导航、关于页面使用的结构化内容。

文章状态分为草稿、待审核、待发布、已发布和已驳回。只有已发布且到达定时时间的文章会出现在前台。文章正文只渲染净化后的 Markdown。评论默认进入待审核状态，只有在内容后台通过后才会公开展示。

## 本地数据说明

默认数据库为 `data/crosspilot.db`。删除本地数据库文件后，下一次启动会重新创建模拟数据。

数据库升级前会在 `data/backups/` 自动创建备份。上传图片保存在 `data/uploads/`，其元数据写入 `media_library`；仅删除数据库而保留上传目录时，可在内容后台重新清理未引用的旧图片。

如需保留自己的测试导入，请先备份 `data/crosspilot.db`。项目不包含登录、云同步和官方平台 API 直连，不建议直接接入未经授权的真实账号数据。
